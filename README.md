## O que estou aprendendo e aplicando no momento
- **Linguagens Base:** Aprofundamento em lógica e estrutura de dados utilizando C, C++ e Python.
- **Fundamentos de Backend:** Criação de servidores web, roteamento, métodos HTTP (GET, POST), regras de CORS e manipulação de Status Codes.
- **Ecossistema JavaScript:** Node.js (utilizando módulos nativos como `http`), JavaScript Vanilla e comunicação assíncrona (`fetch`, `async/await`).
- **Bancos de Dados Relacionais:** Modelagem estruturada, comandos SQL essenciais e integração de APIs com MySQL.
- **Versionamento e Ferramentas:** Fluxo de trabalho diário com Git/GitHub e gerenciamento de dependências locais com NPM.

## Foco Recente
Recentemente, concluí a transição de um sistema de autenticação local (Frontend) para uma arquitetura **Fullstack** real. Construí uma API em Node.js do zero para receber requisições do cliente, processar regras de negócio com segurança e salvar as credenciais de forma persistente em um banco de dados MySQL, compreendendo na prática o ciclo completo de vida de uma requisição web.
